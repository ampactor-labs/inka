# boot/mentl.wasm — the pinned fixpoint compiler

This binary IS Mentl: the wheel compiled by itself to the byte-identical
fixed point (first light, 2026-07-10, commit 87c0152, tag `first-light`).
It replaces the hand-WAT seed as the bootstrap: the default build loop is

    boot/mentl.wasm  compiles  src/**+lib/**  →  m2   (wheel-emitted)
    m2               compiles  src/**+lib/**  →  m3
    assert m2 == m3                                    (the fixpoint ratchet)

Because boot is itself wheel-emitted, m2 == m3 IS the fixed point — the
seed-era rule "NOT m2 == m3" (PLAN §6) compared a SEED-emitted m2 against a
wheel-emitted m3 and retired with the seed.

Provenance, self-confirmed at pin time:

- source: the O(1) reachability index + the LSuspend Int-op_h-as-name root fix
  (2026-07-14). `reachable_from_main` computed the emitted-fn set by calling
  `reach_decl_refs` per frontier name — a linear scan of the whole lowered decl
  list, O(N^2), 58.66% of the self-compile (perf). It is now a one-pass name→refs
  str_hash index read O(1) (`build_reach_index` / `reach_index_get`). The index
  alone hung m2: `reach_names_expr`'s LSuspend arm prepended the SECOND field as
  a reachable name, but that field is `op_h`, an Int op-handle
  (`LSuspend(Int, Int, LowExpr, [LowExpr], List, Bool)`). The scan's `str_eq`
  tolerated the raw Int (length short-circuit); the index's `str_hash` reads it
  as a string pointer (op_h=72051 → data-section text " (local $nc ", byte_len
  0x6f6c2820 = 1.87 GB) and grinds 1.87 billion bytes. Dropping `[o]` — an Int
  is never a decl name — killed the hang AND made reach more precise: boot's
  garbage-tolerant scan spuriously kept `$println` (dead in the compiler binary;
  its only callers are `test.mn`'s unreachable harness), which the leaner reach
  correctly drops (the m2/m3 diff is that one fn + the shifted fn indices).
  m3-gen 56s → 13s (4.3×). Pinned from m3 (m2 != m3 by design — the emit change
  crossing one generation; m3 == m4 self-confirmed 468699 lines; battery 8/8
  rungs + 66/66 micros + 5/5 crown verified THROUGH m3 before the bless).
