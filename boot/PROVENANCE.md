# boot/mentl.wasm — the pinned fixpoint compiler

This binary IS Mentl: the wheel compiled by itself to the byte-identical
fixed point (first light, 2026-07-10, commit 87c0152, tag `first-light`).
It replaces the hand-WAT seed as the bootstrap: the default build loop is

    boot/mentl.wasm  compiles  src/**+lib/**  →  m2   (wheel-emitted)
    m2               compiles  src/**+lib/**  →  m3
    assert m2 == m3                                    (the fixpoint ratchet)

Because boot is itself wheel-emitted, m2 == m3 IS the fixed point — the
seed-era rule "NOT m2 == m3" (PLAN §6) compared a SEED-emitted m2 against a
wheel-emitted m3 and retired with the seed.

Provenance, self-confirmed at pin time:

- source: the image-layout wheel — static closure records seated AT heap_base
  (4096, ending the page-0 collision with io.mn's fs scratch), fd_prestat_get
  registered (fs_dir_fd reads the dir preopen live), the prelude compare
  family on str_eq by name. Pinned from m3 (an EMIT change crosses one
  generation: m2 != m3 by design, m3 == m4 self-confirmed byte-exact)
- boot/mentl.wasm  sha256 d24af35ac8e9c3a74d24c502c7a302bdbe534c483406cbdd895d21715bda87f2
- its .wat (m2 == m3 asserted) sha256 24174966ee1999b11b0ded5e67e859196f4532883921e5f579eb31867ff677cd
- generated by: `bash tools/march.sh` (the ratchet loop, from the
  first-light boot — which was pinned from the cold ladder at
  sha b3314001…, commit 87c0152, tag `first-light`)

Re-pinning (a deliberate act, like updating a lockfile): after a wheel change
reaches its new fixpoint, copy the fresh m2.wasm here, update the hashes
above, and commit with the march output in the message.

The hand-WAT seed (`bootstrap/`) stays as the cold-bootstrap recipe and the
diverse-second-seed ingredient (trusting-trust, PLAN band J:
`Hβ.closure.diverse-double-compilation`). It no longer runs in the loop;
`--from-seed` on verify/march-gate/march walks the full ladder from it.
