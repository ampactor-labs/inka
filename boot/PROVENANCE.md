# boot/mentl.wasm — the pinned fixpoint compiler

This binary IS Mentl: the wheel compiled by itself to the byte-identical
fixed point (first light, 2026-07-10, commit 87c0152, tag `first-light`).
It replaces the hand-WAT seed as the bootstrap: the default build loop is

    boot/mentl.wasm  compiles  src/**+lib/**  →  m2   (wheel-emitted)
    m2               compiles  src/**+lib/**  →  m3
    assert m2 == m3                                    (the fixpoint ratchet)

Because boot is itself wheel-emitted, m2 == m3 IS the fixed point — the
seed-era rule "NOT m2 == m3" (PLAN §6) compared a SEED-emitted m2 against a
wheel-emitted m3 and retired with the seed.

Provenance, self-confirmed at pin time:

- source: M4 — the ABANDON discipline (bank M4, 2026-07-13). An arm that
  never resumes AND returns a meaningful value (a UZero grade over a concrete
  return, `abort() -> Option`) delivers that value as the INSTALL's,
  abandoning the continuation — a distinct `ResumeDiscipline` (Abandon) beside
  OneShot/MultiShot/Either. The perform yields with a dead k; a diverging
  Abandon perform deadens its remainder; the k2 arg-boundary reconstructs a
  CONSTRUCTOR remainder (`Some(risky())`); a foreign yield crossing an
  abandon-armed install propagates (the redrive) or floors (the has_driver
  foreign-yield gate). The classifier gates on the op's return type, so the
  wheel's own `abort -> !` / `fail -> a` stay OneShot (no wheel op flips to
  Abandon); the m2 != m3 diff is purely the k-machinery EMIT change (the
  redrive-propagate + the op="" floor discriminator) crossing one generation.
  Pinned from m3 (m2 != m3 by design, m3 == m4 self-confirmed; battery 8/8 +
  66/66 AND all seventeen k gates — option-protocol flips 0→42, uzero-through-
  frames stays 33, backtrack-full stays 30, resume-across-install stays 134 —
  verified THROUGH m3 before the bless).
